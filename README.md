📍 Türkiye · 🗣️ English, Türkçe

### 🎯 What I Work On

- Ransomware ecosystem tracking: group activity, victim disclosure, and the datasets behind both
- OSINT, SOCMINT and dark web investigation: actor profiling, credential exposure, leaked datasets
- Detection engineering: Sigma and YARA rules derived from public reporting, with the reporting linked
- Exploitation-chain analysis and the technical write-ups that come out of it
- Geopolitical correlation: tying activity to political and military conflict, from an International Relations background rather than as an afterthought

<details>
<summary><b>🧭 How I work</b></summary>

Method is the part intelligence work usually leaves unstated, so I state mine.

- Requirements come first and drive collection, not the other way round
- Sources are graded for reliability before anything is built on them
- Competing hypotheses are tested rather than the first one confirmed
- Every assessment carries an explicit confidence statement
- Actors and campaigns are modelled against MITRE ATT&CK and the Diamond Model, so findings stay comparable over time instead of being one-off notes

</details>

### 🛠️ What I Build

- Threat-feed ingestion and normalization, cross-source deduplication, risk-scoring pipelines
- Monitoring services with multi-channel alerting, running on a schedule instead of by hand
- Report automation: templated generation, document export, publishing without manual steps
- LLM agent pipelines, where grounding and hallucination control are treated as the hard part

Small tools that do one job, document it properly, and keep their legal boundaries in the code rather than in a disclaimer.
